# Git på Gen-Z

## TL;DR

Git kan vara krångligt, men här är en guide för hur du snackar om det på Gen-Z-språk. Vi skippar boomer-termer och går all in på meme-energi.

## The Vibe Check

Nedan följer en lista över vanliga git-verb och substantiv, deras nuvarande bruk samt förslag på hur vi gör det mer cringe (dvs, mer relatable).

### Verb: Coding but make it Gen-Z

| Verb        | Nuvarande bruk | Gen-Z Bruk   |
|-------------|----------------|--------------|
| pull        | pulla          | slurpa       |
| push        | pusha          | yeeta        |
| fetch       | fetcha         | hämta vibbar |
| branch      | brancha        | splitta      |
| commit      | commita        | sätta sin själ |
| rebase      | rebasa         | timeline-hoppa |
| merge       | merga          | fusera       |
| squash      | squasha        | ratioa       |
| stash       | stasha         | bonka        |
| tag         | tagga          | namnge lore |
| cherry-pick | cherry-picka   | simp-picka   |
| amend       | amenda         | retconna     |
| blame       | blamea         | exposea      |

### Substantiv: Vad kallar vi skiten egentligen?

| Substantiv   | Nuvarande bruk | Gen-Z Bruk     |
|--------------|----------------|----------------|
| git          | git            | giga-chad     |
| repository   | repo           | content-dump  |
| branch       | branch         | alt-timeline  |
| commit       | commit         | livsbeslut    |
| pull request | pull request   | slurp-begäran |
| stash        | stash          | goblin-horde  |
| tag          | tagg           | lore-mark     |

## Exempel

- "Kan du slurpa min splittade gren och yeeta den till giga-chad?"
- "Jag sätter min själ på den här feature-branchen."
- "Skicka en slurp-begäran när du timeline-hoppat klart."
- "Låt oss simp-picka från main."
- "Oops, jag råkade ratioa hela content-dumpen.." :skull:
- "Fusera dina livsbeslut innan du slurpar."

## Daily Drip

Såhär fixar du din `.gitconfig` för att maxa Gen-Z vibbar:

```sh
    git config --global alias.slurpa pull
    git config --global alias.yeeta push
    git config --global alias.splitta branch
    git config --global alias.livsbeslut commit
    git config --global alias.timelinehoppa rebase
    git config --global alias.fusera merge
    git config --global alias.bonka stash
    git config --global alias.exposea blame
    git config --global alias.loremark tag

    alias giga-chad=git
```

Skicka en slurp-begäran om du vill lägga till mer cringe.
